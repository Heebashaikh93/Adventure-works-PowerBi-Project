# AdventureWorks Power BI Dashboard

This project is an interactive Power BI dashboard built using the **AdventureWorks** sample dataset. It provides business insights through visual analytics and KPI tracking.

## Features
- Executive Dashboard with key performance indicators
- Product and Customer analysis
- Geographic sales map
- Decomposition Tree analysis
- Key Influencer analysis
- Anomaly Detection visuals
- Calculation Groups implementation

## Tools Used
- Power BI Desktop
- DAX
- Power Query

## Files
- `AdventureWorksReport.pbix` – Main Power BI report file

## Purpose
The project demonstrates data visualization, business analysis, and reporting skills using Power BI. It is intended as a portfolio project for analytics and business intelligence roles.
